# Claude Fable 5

Claude Fable 5 is the first model in Anthropic's Claude 5 family and part of a new **Mythos-class** model tier that sits above Claude Opus in capability. It is the most intelligent generally available Claude model.

## Model Tier

Claude Fable 5 and **Claude Mythos 5** share the same underlying model, differentiated as follows:

- **Claude Fable 5** — the generally available version; includes additional safety measures for dual-use capabilities.
- **Claude Mythos 5** — available without those measures to approved organizations only.

## Model ID

claude-fable-5

## Access

Claude Fable 5 is accessible through multiple surfaces:

- **claude.ai** — web, mobile, and desktop chat interfaces
- **Claude API / Claude Platform** — programmatic access
- **Claude Code** — agentic coding tool (CLI, desktop app, mobile app)
- **Claude Cowork** — agentic knowledge-work desktop app for non-developers
- **Beta products** — Claude in Chrome, Claude in Excel, Claude in PowerPoint
